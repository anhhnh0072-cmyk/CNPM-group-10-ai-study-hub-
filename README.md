# AI Study Hub - Hệ thống Quản lý Tài liệu Học tập AI

## Giới thiệu

AI Study Hub là hệ thống web hỗ trợ sinh viên quản lý tài liệu học tập tập trung và thuận tiện hơn.

Hệ thống cho phép:
- Upload và quản lý tài liệu học tập
- Lưu trữ file trên cloud
- Tìm kiếm tài liệu nhanh chóng
- Tải xuống và xem trước tài liệu
- Sử dụng chatbot AI để hỗ trợ học tập

---

# Mục tiêu dự án

Hệ thống được xây dựng nhằm:
- Hỗ trợ sinh viên quản lý tài liệu tập trung
- Giảm thất lạc tài liệu học tập
- Tăng khả năng tìm kiếm và truy cập tài liệu
- Tạo môi trường chia sẻ tài liệu thuận tiện
- Ứng dụng AI chatbot hỗ trợ học tập
- Làm quen quy trình phát triển phần mềm Fullstack thực tế

---

# Chức năng chính

## 1. Authentication
- Đăng ký tài khoản
- Đăng nhập
- Đăng xuất
- Quên mật khẩu
- Cập nhật thông tin cá nhân

## 2. Quản lý tài liệu
- Upload tài liệu
- Xem danh sách tài liệu
- Tải xuống tài liệu
- Xóa tài liệu
- Chỉnh sửa thông tin tài liệu
- Xem chi tiết tài liệu
- Tìm kiếm tài liệu
- Lọc tài liệu theo môn học

## 3. Cloud Storage
- Upload file lên cloud
- Xem trạng thái upload
- Preview file trực tiếp

## 4. AI Chatbot
- Chat với AI chatbot
- Hỏi đáp nội dung học tập
- Nhận phản hồi AI
- Xem lịch sử chat
